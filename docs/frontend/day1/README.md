对应分工表第 1 天「前端：梳理页面清单、用户流程与线框」，以及当日互审要达成的
「确定接口约定、字段和枚举」。

项目：**ledger-guard 智能记账与消费干预系统**（SRS 见仓库根目录 `README.docx`）。

| 文件 | 说明 |

## 阅读顺序（评审建议）

1. 文档 §0 当天结论 → §4 页面清单与状态矩阵 → §5 用户流程；
2. 打开 `wireframes.html` 逐张过线框（投屏比文档更清楚）；
3. 回到文档 §7 接口约定与 §9 待确认问题，逐条拍板（每条都有默认决策）。

## 重新生成

脚本依赖 Python（python-docx）与本机 Chrome（用于画板截图）。

```powershell
# 1) 重出线框看板与 PNG（改动 gen/pages.py 或 gen/ui.py 后执行）
python docs/frontend/day1/gen/build_html.py

# 2) 重出 DOCX（改动 gen/docx_*.py 后执行）
python docs/frontend/day1/gen/build_docx.py
```

- 画板内容与文案：`gen/pages.py`（17 张画板 + D01 流程总览）
- 视觉令牌与组件样式：`gen/ui.py`
- 文档正文：`gen/docx_part1.py`（封面 / 0 / 1–3）、`docx_part2.py`（4–5）、`docx_part3.py`（6–11）

Chrome 路径写在 `gen/build_html.py` 的 `CHROME` 常量，如本机位置不同需改一行。
